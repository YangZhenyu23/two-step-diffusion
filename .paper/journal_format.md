# Journal Format

This is not a journal submission. It is a course-group reproduction excerpt
for MATH7600 / HKU, covering only the KPP experiments that correspond to
Sections 4.3 and 4.4 of Shen et al., arXiv:2601.20024v1.

- Language: English (match the source paper's scientific register).
- Citation style: author-year or numbered is acceptable; keep citations minimal.
- No abstract, introduction, KS sections, or global conclusion.
- Standalone compilable PDF that can later be dropped into the group manuscript.
- Word limit: none. Target 6-10 pages including figures.
- Journal compliance was not checked.
